# Component research

[English documentation](README.md)

| Candidate | What BlueFaber would evaluate |
| --- | --- |
| [PluginBlueprint](https://github.com/InventivetalentDev/PluginBlueprint) | A visual editor and Java plugin generation. Test whether useful pieces can be separated from its project format. |
| [Kerlann Blueprint](https://github.com/Kerlann/blueprint) | Typed ports, extensible nodes, and preservation when an extension is unavailable. Assess its dependencies on Minecraft types and execution model. |
| [React Flow](https://github.com/xyflow/xyflow) | A canvas option for a TypeScript interface backed by a JVM worker. Compare accessibility, large graphs, node types, and diagnostics. |
| [Vineflower](https://github.com/Vineflower/vineflower) and [CFR](https://github.com/leibnitz27/cfr) | Independent decompiler outputs. Compare rebuild rate, API coverage, and behavior on a pinned bytecode corpus. |
| [Architectury](https://github.com/architectury/architectury-plugin), [Connector](https://github.com/Sinytra/Connector), [Launchpad](https://github.com/Sinytra/Launchpad) | Existing approaches to cross-loader builds, runtime compatibility, and development. Document prerequisites and compare with a native port. |

Record exact revisions, file licenses and dependency boundaries. Use one graph for the canvas comparison and a separately maintained input corpus for the recovery comparison.

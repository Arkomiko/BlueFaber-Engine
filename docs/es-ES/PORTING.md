# Importación y portabilidad

[Español](README.md)

Fija la versión del juego, el cargador, Java, las dependencias y el entorno del cliente o servidor para cada lado. El editor debe conservar el JAR, mostrar qué nodos se recuperaron y localizar los bloqueos. Compilar y reproducir el comportamiento en juego son comprobaciones separadas.

Los perfiles contemplan Forge, NeoForge, Fabric, Bukkit, Spigot y Paper. Un plugin de servidor puede reproducir una receta compatible; los registros nuevos y las funciones del cliente requieren capacidades adicionales. [Guía en inglés](../en-US/PORTING.md)

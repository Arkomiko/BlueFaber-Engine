# Plantillas editables

[Español](README.md)

**BLUSTREE** reúne árboles, bloques de madera, puertas, cercas, herramientas y embarcaciones. **BLUSMOR** cubre minerales, fundición, armaduras, vehículos, mecanismos, tridente y pararrayos.

Cada paquete se inserta como un grafo que puedes abrir, editar y volver a guardar. Los primeros ensayos usan un tronco y tablones para BLUSTREE, y una receta de fundición para BLUSMOR. [Especificación en inglés](../en-US/TEMPLATES.md)

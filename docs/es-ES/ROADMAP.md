# Plan de desarrollo

[Español](README.md)

BlueFaber busca trasladar mods y plugins de Minecraft Java Edition entre versiones y plataformas. El primer ensayo compara Fabric 1.21.1 y 1.21.4 en ambas direcciones, con un JAR de entrada independiente, una receta y un modelo. El resultado se comprueba dentro del juego.

El plan va del inventario del JAR y la recuperación de Java al grafo editable y la compilación de destino. Después se amplían las reglas de Mixin, los cargadores, las plataformas de servidor y las versiones históricas. [Plan detallado en inglés](../en-US/ROADMAP.md)

# विकास योजना

[हिन्दी](README.md)

BlueFaber का मुख्य लक्ष्य Minecraft Java Edition के मॉड और सर्वर प्लगइन को अलग संस्करणों और प्लेटफ़ॉर्म पर पोर्ट करना है। पहली जाँच Fabric 1.21.1 और 1.21.4 के बीच दोनों दिशाओं में होगी। हर दिशा के लिए अपना JAR, एक रेसिपी और एक आइटम मॉडल होगा।

योजना में JAR की जाँच, Java की पुनर्प्राप्ति, नोड संपादन और लक्षित बिल्ड शामिल हैं। उसके बाद Mixin, दूसरे लोडर और पुराने संस्करणों का समर्थन जाँचा जाएगा। [विस्तृत योजना अंग्रेज़ी में](../en-US/ROADMAP.md)
